DIGITALGYYAN — MASTER UPLOAD GUIDE

READ FIRST
- index.html is the main homepage.
- catalog.json lists existing Visual Simulation and Assessment HTML tools.
- Do not delete existing project folders.
- When you upload a new version to Netlify, deploy the complete project folder to the SAME site. Do not delete the site first.
- Static hosting does not automatically show newly copied files. New HTML tools must be added to catalog.json; PDFs need a visible link on the appropriate resource page/catalog. You can send me the files and I can update these listings.

G) PUBLISHING
1. Add files to the correct folder.
2. Update catalog.json or the resource page so the new file has a visible link.
3. Upload/deploy the complete updated project folder to the same Netlify site.
4. Verify the new link on the live website.
No need to delete the existing website first.

NOTE: This ZIP creates folder structures and placeholder .keep.txt files; it does not invent or include future PDFs.
